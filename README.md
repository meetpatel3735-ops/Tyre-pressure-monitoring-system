# Tyre-pressure-monitoring-system
1. Our project is a Puncture Safe Emergency Wheel System designed to improve road safety.
2. The main purpose is to detect tyre pressure loss or a puncture at an early stage.
3. A TPMS sensor can continuously monitor the tyre pressure.
4. When pressure drops below a safe level, the system gives an early warning to the driver.
5. An Arduino/ESP32 is used to process the sensor data.
6. An LCD display shows the current tyre pressure.
7. A green LED indicates that the tyre pressure is in the safe range.
8. A red LED and buzzer activate when the pressure becomes critically low.
9. The emergency mechanism is designed to help the vehicle maintain temporary stability after a puncture.
10. This can reduce the risk of loss of vehicle control and accidents.
11. The system is intended to be low-cost, compact, and easy to install.
12. Our project provides a practical solution for safer driving and emergency tyre management.
